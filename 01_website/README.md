# เว็บไซต์แคตตาล็อก Triple E Trading (ทริปเปิ้ล อี เทรดดิ้ง)

เว็บไซต์ static (HTML + CSS + JavaScript ล้วน ไม่ต้องมีเซิร์ฟเวอร์/ฐานข้อมูล) ดีไซน์ v7 แนวร้านค้าออนไลน์ (อ้างอิงเลย์เอาต์ fitsole.shop)
พื้นขาว ตัวอักษรดำ ช่องรูปสินค้าเทาอ่อน ปุ่มเหลี่ยมดำ สีเน้นส้ม 3E #F7931E · โลโก้ 3E เวกเตอร์ `images/brand/3e-logo.svg`
ฟอนต์ (Google Fonts): Instrument Sans (อังกฤษ) + IBM Plex Sans Thai Looped (ไทย) + IBM Plex Mono (ราคา)
โลโก้แบรนด์สินค้า 27 แบรนด์อยู่ที่ `images/brands/` แบรนด์ที่ไม่มีโลโก้แสดงเป็นป้ายชื่อ
มี 2 ภาษา (TH/EN) และโหมดมืด/สว่าง

## เปิดดู
- ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย (ต้องต่อเน็ตเพื่อโหลดฟอนต์)
- อัปโหลดทั้งโฟลเดอร์นี้ขึ้นโฮสต์ใดก็ได้ (Netlify, Vercel, GitHub Pages, cPanel) ใช้ได้ทันที

## หน้าในเว็บ
| ไฟล์ | หน้า |
|---|---|
| `index.html` | หน้าแรก: สไลด์ 3 แผ่น, สินค้าขายดี, กลุ่มสินค้า, สายไฟ YAZAKI, แบรนด์, หมวดยอดนิยม, แถว OMRON/SHINOHAWA, ใบขอราคา, เรื่องของเรา, FAQ, LINE |
| `catalog.html` | สินค้าทั้งหมด: ค้นหา (ชื่อ / รหัสรุ่น / แบรนด์), กรองหมวด-แบรนด์, เรียงราคา · ลิงก์ตรงได้ เช่น `catalog.html?brand=omron`, `catalog.html?cat=circuit-breaker`, `catalog.html?q=MY2N` |
| `product.html?p=<slug>` | หน้าสินค้า: รูป, สเปค, กล่องเลือกรุ่น, ตารางรุ่นย่อย+ราคาตั้ง, ปุ่ม + เพิ่มใบขอราคา, สินค้าที่เกี่ยวข้อง · สายไฟ: สเปคชีต + ตารางราคาขนาด×แกน |
| `quote.html` | ใบขอราคา: ใส่จำนวน, รวมราคา, คัดลอกส่ง LINE/อีเมล, พิมพ์/PDF, ดาวน์โหลด CSV |

## แก้ข้อมูล
- ข้อมูลบริษัท (ชื่อ, ที่อยู่, เบอร์โทร, อีเมล, LINE) → `data/config.js`
- โลโก้แบรนด์ → `images/brands/<ชื่อแบรนด์>.png` และรายการใน `data/brand-logos.js`
- ข้อมูลสินค้าบนเว็บ → `data/catalog.js` และ `data/skus.js` (สร้างจากฐานข้อมูลใน `database/`)
- รูปสินค้า → `images/products/` (ไฟล์ .webp ขนาดใหญ่ + `-480.webp` สำหรับการ์ด)

## ฐานข้อมูล
ดู `database/README.md` — มี SQLite, JSON, CSV, Excel ใช้ต่อกับเว็บอื่น/WooCommerce/ระบบหลังบ้านได้
