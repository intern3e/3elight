## ข้อมูลสำคัญ
- **product** = กลุ่มรุ่น/ซีรีส์ 1 หน้าสินค้า · **sku** = รหัสสั่งซื้อ 1 รหัส ที่ราคา 1 ราคา (2P/3P/4P, แรงดันคอยล์ ฯลฯ แยก SKU ใส่ไว้ใน `option`)
- `list_price` = ราคาตั้งตามใบราคา ส่วนใหญ่ **ไม่รวม VAT** · "สอบถามราคา/เลิกผลิต" → `list_price` ว่าง ข้อความอยู่ใน `price_note`
- `discount_pct`, `net_price` ว่างทั้งหมด (ใบราคาไม่มีส่วนลด) เตรียมไว้ให้กรอก
- รุ่นซ้ำหลายใบราคา ใช้ใบใหม่สุด ราคาเก่าอยู่ `price_history`
- คอลัมน์ `*_en` = คำแปลภาษาอังกฤษ (แปลด้วย AI 5,187 ข้อความ ควรให้ทีมขายสุ่มตรวจศัพท์เทคนิค)
- สายไฟ YAZAKI: ราคาเป็น บาท/เมตร · `products.spec_sheet_json` เก็บสเปคเต็ม + ตารางขนาด×แกน
- `image_quality`: high / medium / low (low ไม่แสดงบนเว็บ เก็บไว้ที่ `images/lowres/` เพื่อหารูปใหม่)
